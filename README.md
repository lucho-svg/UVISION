# UVISION

☀️ Acerca del Proyecto
UVISION es una solución escolar de tecnología cívica y código abierto diseñada para proteger a estudiantes y docentes frente a los niveles críticos de radiación solar en Tacna.

A través de un semáforo físico automatizado con Arduino Uno y el sensor analógico ML8511, el sistema mide en tiempo real la radiación UV en el mismo patio del colegio y traduce los datos numéricos en una señal visual universal e intuitiva (verde, amarillo, rojo y violeta), alineada a la escala oficial de la OMS. Además, integra una plataforma web con telemetría en vivo y alertas automáticas, ofreciendo una alternativa accesible, replicable y de bajo costo frente a las estaciones meteorológicas comerciales para promover una cultura de prevención y cuidado de la salud de toda la comunidad educativa.
